Mardar 是一款本地优先的跨平台 Markdown 写作与阅读工具。点击即写、所见即所得，公式、图表与代码开箱即用，一键导出精美 PDF。

专注写作所需的一切

不需要账号，不上传文档。文件就在你的磁盘上，Markdown 源码保持原样。

✎即时编辑点击页面任意位置直接开始写作，当前段落显示 Markdown 源码，离开即渲染，方向键在段落间自由穿梭。
◫四种视图即时编辑、纯源码、分栏实时预览与阅读模式，分栏滚动和光标位置双向同步。
ƒx数学公式KaTeX 离线渲染行内与块级公式，内置常用公式模板。
◇Mermaid 图表流程图、时序图、甘特图等，写代码块即可生成图表。
</>代码高亮主流编程语言语法高亮，工具栏一键插入代码块。
↓PDF 导出原生 A4 排版导出，公式、图表、代码与图片完整保留。
▧图片与 HTML拖入、粘贴或插入图片，支持相对路径与内嵌 HTML，并自动清理不安全内容。
◐深色主题与大纲护眼深色主题、文档大纲导航、字符统计与最近文件。
